# 0.3 行走手感与技能连携

用户反馈：上下坡、贴边及普通行走有间歇卡顿；技能联动不够强；标准难度需要略微提高。保留当前 Three.js 第三人称游戏、四技能加地图支援、单次复起与完整旧港。

## 本轮实施方向

- 以连续位移/高度与浏览器帧时间分别复现碰撞停顿和渲染停顿，不能仅靠最终能抵达判定流畅。
- 五条跨能力连携：牵引重击、感电爆破、雷云共振、蓄能反击、蜂群集火。触发有冷却限制，次生伤害不递归触发其他连携。
- 升级优先提供能补齐当前连携的技能；展示获得/替换后点亮或断开的具体回路。
- 标准难度适度增加追击、精英组合波与首领压力，保留清杂兵能力、复起和近战生存收益。
- 保留 v2 存档；新状态字段可缺省恢复。变更前源码在 archive/v0.2-before-feel-update。

## 已落实的规则

| 连携 | 组成 | 实际触发 |
|---|---|---|
| 牵引重击 | 钩索 + 重拳 | 聚怪后重置重拳，下次拳击追加震地；即使钩索先击败目标也完成冲击 |
| 感电爆破 | 电泡/电炮 + 连雷/钩索/导电涂层 | 命中导电敌人消耗其标记，向其他目标跳跃放电，0.75 秒触发间隔 |
| 雷云共振 | 雷雾 + 连雷 | 雷电击中雾内敌人，引发雾区震击并加速放电 1.8 秒 |
| 蓄能反击 | 圆盾 + 重拳/钩索 | 按实际吸收伤害蓄能，下次近战释放反击波 |
| 蜂群集火 | 机械蜂 + 连雷/钩索/导电涂层 | 优先导电目标，三次命中追加协同齐射，1.4 秒触发间隔 |

追加伤害有独立来源及触发冷却，不互相递归套用。统计显示真实命中伤害，并注明已计入对应能力总伤害。修复旧连雷在伤害结算后才标记的顺序问题，秒杀也能触发殉爆。

标准档：敌人生命、移速与伤害各提高 12%；脱战回血从 2.5 秒后每秒 3.5 改为 3.5 秒后每秒 2.8。每隔 150 秒（到第 600 秒为止）提前 5 秒预告一组两精英加六普通炮机/冲锋机。终局首领生命从 18000 调至 28000。玩家初始生命、一次复起、闪避无敌、近身回收和默认四次重抽保持原值。

## 行走与画面

物理控制器接管连续重力和接触高度，不再每步把人物压回地图理想高度；西坡边货箱移出通行带。攻击仍可瞄准敌人，但不再抢走移动中的人物朝向。特效方向独立记录。

角色和相机在显示帧之间插值；奔跑动画按模拟步位移判断。首次效果在载入界面预热，伤害数字缓存画布尺寸并使用变换定位，避免每帧读写布局。测量显示保存耗时不足 1ms，因此没有把保存当作未经证实的主因改造。

密集连携曾暴露新的耗时尖峰：范围攻击即使处于连携冷却中仍重复查找并排序全部敌人。现在先判断冷却，再查找目标；单目标选择改用线性最近查询，机械蜂表现层复用一次查询。相同压力场景的触发次数、连携伤害和玩家受伤完全一致，没有通过降低效果或改变伤害来掩盖停顿。

性能样本来自本机 Apple M1 Max、Chrome 152、中画质、1920×1080；普通战斗与人为密集压力场景分开记录。自动整局验证规则和地图集成，不等于真人胜率或乐趣已经验收，也不保证所有设备都达到相同帧率。当前标准档仍有较高容错，新增压力主要要求留意增援、走位和技能组合。
