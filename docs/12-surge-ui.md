# 电涌 UI 实现

此文档记录新版 `src/surge/ui.ts` 与 `src/surge/style.css`，不修改 Oinja 原作设定。

视觉方向是暖橙、青绿和深海军蓝。主菜单左侧配置与标题承载信息，右侧保留真实 3D 旧港和角色。战斗 HUD 集中在角落，中部和下方中间留给战场；没有手机虚拟摇杆，窄窗口只保障菜单与弹层可读。

## 接口

`new SurgeUI(root, callbacks)` 挂载独立 DOM。公开方法：`menu(profile, hasSave)`、`loading(progress,label)`、`hud(state,region)`、`choices(state)`、`pause(state)`、`result(state,unlocked)`、`map(state,world)`、`toast(text)`、`game()`、`settings(profile)`、`destroy()`、`handleKey(event)`。`isOverlayOpen` 是只读状态，宿主据此控制输入与镜头。

`UIActions.start(weapon,danger,kit?)` 的第三个参数默认为 `balanced`，其它回调遵循主线程约定。UI 只维护呈现状态。暂停、保存、战斗推进、技能效果和成就由主线程处理。

## 流程

- 八种初始能力首局开放；危险合约 0、1、2；展开后可选带收益与代价的开局方案。未解锁方案禁用。
- 四能力槽与独立支援槽分开。满槽选择新能力时先显示替换页，最后发出 `choose(id,slotIndex)`；升级与进化直接发出 `choose(id)`。
- 升级页支持数字 1–3、R 重抽。替换页支持 1–4，Esc 返回。弹层有键盘焦点环与循环。
- 暂停显示构筑、改装和操作，支持设置和保存返回菜单。设置即时回调：音量、质量、镜头距离、震动、伤害数字、减少动态。
- 地图使用 `world.bounds`、区域、场景碰撞体、玩家坐标及事件状态绘制 SVG。事件通路来自真实 `findPath`，不显示密集寻路网格；跨层路线以暖色虚线区分，断开的捷径为暗色虚线。
- 结算显示战斗统计、各能力实际伤害条、最终构筑、独立支援与本局新解锁。档案页显示累计记录，开局方案是横向取舍。

## 接入注意

宿主调用 `handleKey` 后，返回 `true` 时不要再交给战斗输入。UI 开启地图只发出 `map()`，由宿主暂停模拟；返回只发出 `resume()`。升级弹层不接受 Esc 跳过选择。`hud` 可持续传入新状态，不会重建整个 HUD。请仅导入 Surge 样式，避免旧版全局样式覆盖。

## 2026-09-19：自动连携界面

规则展示来自 `src/surge/synergies.ts`，UI 不维护第二份触发条件。五条连携为牵引重击、感电爆破、雷云共振、蓄能反击、蜂群集火。

- 新能力与改装卡使用 `previewChoiceSynergies` 显示“接入后点亮”与具体触发结果。普通改装的标签写“适配”，与已接通的命名连携区分。
- 满四槽时卡片预告是条件式：“换入可点亮 · 需保留搭档”。进入替换页后逐槽调用预览，列出新点亮、断开或全部保留，不把第五把武器当作真实构筑。
- 战斗 HUD 在已有能力槽上方增加一行连携数量和最近触发名，隐藏未接通的空状态。两个文本节点在初始化时缓存；构筑签名或实际文字变化才更新，不增加持续动画，也不重建 HUD。
- 暂停页解释当前已接通连携的组成、触发规则、真实次数及伤害；未触发时明确写“尚未触发”。结算保留曾经触发但后来换出的连携，并说明其伤害已包含在能力伤害中。
- 操作说明由同一份运行规则定义生成。旧存档缺少联动统计时按未触发展示。

专项证据目录：`artifacts/synergy-ui/`。`verify-ui.mjs` 在独立浏览器上下文中准备钩索/重拳和附近高生命敌人，随后由真实自动模拟产生联动次数与伤害；不伪造触发统计。其余选卡、替换、结算使用准备好的状态验证展示。已有桌面与窄窗口截图；最终运行结果见 `qa-report.json`。这组证据不代替自然长局平衡验证。

本次专项最终结果：15/15 通过、0 浏览器脚本异常。真实自动钩拳造成 1 次触发和 270 联动伤害；100 次同状态 HUD 更新没有重建/修改连携节点。另验证钩索先击败唯一小怪后，准备好的重拳仍自动释放并出现在 HUD。1280×800 与 390×844 截图已目视检查，卡片前鼠标已移开。
