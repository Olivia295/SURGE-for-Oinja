# 0.4 双地图、随机事件与双语

2026-09-20。按用户本轮要求，放慢升级曲线、增加一张地图，加入更有变化的随机事件，支持英文并连接 Oinja 自设网站。所有变更在 Oinja-game，旧版源码保存在 archive/v0.3-before-worlds-update。

## 设计边界

保持第三人称自动作战、四格能力、独立地图支援、八种能力及五条连携。新增场景与事件是本游戏的玩法改编，不写入原角色设定。Oinja 官网仅以明确外链连接，不复制或修改网站内容。

## 双地图

主菜单选择旧港工坊或潮汐观测庭。地图随本局存档，继续、重开均恢复正确场景；旧存档默认旧港。

潮汐观测庭使用原创程序建模，白石与铜绿结构、温室、水庭、观测设备形成不同于旧港货场的视觉。高架观测环廊连接宽缓坡，地面有多条环路与可穿行空间。保留六类设施，每类两处候选，每局抽取其一。

## 成长节奏

新经验曲线与选卡间战斗窗口减少反复中断，保留经验与升级积压，不丢弃玩家收益。旧版存档保留等级、能力、改装与待选择卡片，经验按当前进度比例迁移。

## 随机遭遇

随机事件与永久设施分开：局内出现预告后，玩家在有限时间内按 E 自愿接取。一次最多一个事件；失败或忽略不会扣除永久构筑。奖励即时兑现，不占地图支援槽、不再弹一次升级卡。

- 磁暴猎场：在指定区域连续击杀。
- 流动电池：依次到达回收点。
- 过载交换：接受短暂风险，换取战斗增益。
- 故障分身：追猎指定精英，可以将它们引出接取地点。

地面标记、倒计时与进度提示对应实际状态。已接任务、限时增益和随机序列随存档保留。

## 语言与宇宙入口

中文 / English 切换保存在本机，覆盖游戏操作、能力与进化、连携、设施、随机事件、设置和结算；切换不重开当前行动。菜单、暂停与结算提供「Oinja 宇宙 / Oinja Universe」入口，新标签打开 https://oinja-website.vercel.app ，战斗 HUD 保持简洁。地址在本轮确认 HTTP 200。
