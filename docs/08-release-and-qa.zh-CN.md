# 发布与验收记录

记录日期：2026-09-18（Australia/Sydney）。状态：**本地可玩首版 v0.1；功能、资源、正式构建和本机压力检查通过。四次真实时长脚本试玩完成，真人体验与自然通关平衡尚未签收。**

本文是当前实现的证据索引。`01`—`07` 保留制作蓝图与已确认决策，其中的目标数值和制作关卡不能单凭存在文档就视为通过。项目尚未部署公网。

## 当前实现范围

已有原生 TypeScript + Three.js + Rapier 运行时、两张可切换 3D 港区、角色与五类敌人的运行时模型/动画、自动普攻和六种主动能力、两臂与同调机制、两种模式、经验与升级、技能进化、设施事件、终局主机、胜败及超时结算、本地存档、音乐音效及中文 UI。

主菜单直接展示实时地图和角色。设置、指南和图鉴为 DOM 面板；游戏模拟不在 UI 类中维护。HUD 保留画面中心与角色脚下空间。菜单、升级、设置和结果支持键盘操作；Tab 地图会暂停并释放鼠标，再按 Tab 继续。

当前外观解锁目标尚未由独立奖励服装实现；已实现的局外进展是设置、记录与技能第二进化分支解锁。所有新增敌人与玩法属于本游戏改编，不自动改变原始 Oinja Canon。

## 验证环境与复现

- 已验证环境：Apple M1 Max、32 GB 内存、macOS 26.4、Node.js 25.8.0、Google Chrome 152.0.7977.83。
- 浏览器自动化：Playwright，桌面 1440×900 和 1024×768，`deviceScaleFactor=1`。
- UI 截图使用无头 Chrome；终局性能测试已读取实际图形后端为 ANGLE Metal / Apple M1 Max，使用硬件图形加速。性能结果只适用于本机和本测试，不代表蓝图中的 M1 / 8 GB 低配目标。
- 启动：`npm install`，`npm run dev -- --port 4175`，访问 `http://127.0.0.1:4175/`。
- 规则检查：`npm test`。生产构建：`npm run build`，产物在 `dist/`。
- 浏览器 QA 脚本：`artifacts/ui/flow-checks.mjs`、`artifacts/ui/evolution-and-keyboard.mjs`；当前脚本指定本机 Chrome 路径及端口 4175。
- `window.__OINJA__` 仅在开发/QA 构建提供测试入口，生产默认构建不暴露该入口。

### 浏览器主流程如何触发

1. **菜单和设置**：真实点击两图、两模式与技能选择。将入门右臂重绑到 W 被冲突检测拒绝，改为 G 成功；关闭震动和开启减弱动态可操作；指南随后展示 G。图鉴严格显示五类敌人。
2. **升级**：通过开发入口注入 25 点经验，由实际模拟规则触发升级；确认三个可选项，重抽次数减一，按数字 1 选中后返回游戏。没有直接伪造升级 DOM。
3. **进化**：调试准备四级钩爪及已解锁第二分支，再经实际经验升级生成两个候选；按数字 2 后，技能达到五级并锁定 B 分支。此项不证明整局自然获得该构筑的概率。
4. **地图**：键盘 Tab 打开战术地图，模拟进入暂停、鼠标解锁；等待 500 毫秒，游戏时间不变；再按 Tab 恢复。
5. **存档**：升级后暂停、退回菜单、刷新页面，点击继续；时间与等级 2 被准确恢复，恢复后先停在暂停界面。
6. **失败**：调试注入致死伤害，经过实际死亡规则显示失败、时间、构筑和再来一局按钮。这是伤害链路验证，不是自然被敌人击杀的长局测试。
7. **四种组合胜利**：分别真实启动两图 × 两模式，调试推进到 12 分钟，生成实际织网主机并经模拟伤害接口击破，进入真实胜利回调与结算。没有跳过终局规则直接画成功页；也不能据此宣称自然通关。
8. **超时**：调试推进至 1079.98 秒，再执行模拟步长，触发实际 18 分钟超时失败。
9. **窗口适配**：1024×768 下没有横向页面溢出，开始按钮可见，设置面板可内部滚动；1440×900 的完整桌面布局已截图实看。

## 已知制作边界

- 角色从原始展示模型的只读副本改编，新增减面、材质、骨骼权重和游戏动画；不能称为全部从零建模，也没有改写原始文件。
- Oinja LOD0 约 34,704 三角面，超过初始 30k 预算约 4.7k；LOD1 为 10,273。本机 220/260 活跃单位性能已测量，见下表；低配设备仍未验证。
- 无面部动画或动作捕捉；横移和倒退复用跑步动作，步行动作调整跑步节奏；衣物和背包使用骨骼权重，不做独立物理。
- 技能动画提供姿态，绳索、形态挂件、命中与电力效果由运行时组合。
- 终局织网主机复用并强化织网机模型，没有独立电影级 Boss 模型。
- 尚无独立奖励服装资产；不得把蓝图中的外观目标称为交付完成。
- 战术地图是区域与连接关系示意，不是每面墙和碰撞体的精确俯视导航图。
- 存档为当前浏览器当前源的 localStorage，未提供云同步、账号或跨设备恢复。

详细资产边界见 `art/reviews/ACTORS-README.md`。
